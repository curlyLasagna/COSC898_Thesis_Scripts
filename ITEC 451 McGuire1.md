## Fall 2020 Course Syllabus

Course Objectives: Upon completion of this course, students will have successfully performed one or more of the following:

-  Gain an understanding of tasks associated with database administration
-  Enhance skills in data modeling, normalization, and database design
-  Enhance skills in SQL and learn how to develop stored procedures and triggers
-  Setting up a database server environment
-  Understand and use database transactions
-  Understand database tuning in terms of system, database, and application performance
-  Develop hands on experience with tuning a real-world database.
-  Understand aspects of database integrity including structural and semantic data integrity
-  Develop a thorough understanding of database security planning and implementation
-  Understand issues associated with disaster planning and database backup and recovery.

## Major Topics Studied:

-  Data and databases
-  Data modeling and normalization
-  Database design
-  Structured Query Language (DDL and DML)
-  Stored Procedures
-  Triggers
-  Transactions
-  Database Performance
-  Database Integrity
-  Database Security
-  Database Backup and Recovery

Instructional Methods : The course will consist of lectures, discussions, demonstrations, lab exercises, assignments, group projects, and exams.

Class Preparation: Students should come to class prepared to solve database problems and develop database code.

Assignments: Literature review, written and hands-on assignments will be assigned which provide experience with database management. Details on due dates and submission will be given in the assignments section of the Blackboard Site. Assignments must be submitted on time. A grade of 0 will be given to assignments that are submitted after the due date.

Labs: Lab exercises will provide hands-on experience with database management techniques using MS SQL Server.

Exams: There will be a mid-term and a final exam.  Exams will include questions from lectures, discussions, readings and labs.

Project: The class project will be assigned at the start of the semester. The final project will be a team project require students to apply what they have learned in the class to the design, implementation, and management of a real-world database.  The details of the project will be discussed in the first two weeks of the semester.  It is important to note that this is a project driven course and it is imperative that you make sure the project is completed well and that each student contributes equally to the success of the project.
